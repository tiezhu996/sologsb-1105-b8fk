# 老地图图幅编目与地名对照台

面向古地图整理者和地方志研究者，将老地图按图幅编目，登记年代、比例尺、投影和扫描件，并建立古今地名对照及沿革线索。应用为纯前端单页程序，所有资料保存在浏览器本地。

## Docker 一键启动

```bash
cp .env.example .env && docker compose up -d --build
```

服务默认映射到宿主端口 `21805`。停止服务可执行：

```bash
docker compose down
```

## 数据存储说明

应用使用 IndexedDB 持久化数据，Dexie 数据库名为 `gboldmap-db`。数据库包含 `sheets`、`scans`、`placePairs`、`histories` 四张业务对象仓库，以及本地检索专用的 `searchDocs`、`searchDirty`、`searchMeta` 三张索引仓库：

- `version(1)` 建立首版索引结构，并在首次创建数据库时写入图幅、扫描件、地名对照和沿革种子数据。
- `version(2)` 保持现有索引并对已有图幅执行 `schemaRev = 2` 的回填迁移，用于演示后续结构升级路径。
- `version(3)` 增加本地检索索引：`searchDocs` 存放按条目反规范化的检索文档（确定性主键 `sheet:{id}` / `place:{id}`），`searchDirty` 登记待重算的受影响条目，`searchMeta` 保存分批重建检查点与阶段状态。

刷新或关闭页面不会丢失新增记录；浏览器站点数据被清除时会重新触发首次种子数据写入。

## 本地检索说明

针对馆藏规模增大后「全量读入内存、搜索卡死、重开从头再来」的问题，检索完全在本地索引上完成：

- **不全量入内存**：检索沿 `searchDocs` 主键游标分批扫描（每批 80 条并让出事件循环），内存中只保留当前页（默认 20 条）命中，命中文档再按外键批量水合图幅、扫描件与沿革关联链。
- **增量重算**：新增 / 修改图幅、扫描件、地名或沿革时，只把受影响条目写入 `searchDirty` 并仅重算这些文档（扫描件与图幅变化级联到该图幅地名文档），完成后整批替换并递增 `docsRev`。
- **结果快照隔离**：索引更新期间页面保留上一版完整结果并显示「更新中」标记；新结果整批原子替换，未算完不与旧条目混排。首次建立且没有旧结果时只显示建立进度。
- **分批重建与检查点**：首次建立或完整性校验发现视图损坏（条目数不符、孤儿文档等）后，按 200 条 / 批重建，每批完成即落检查点（阶段 + 主键游标 + 已建数）；失败、取消或页面重开后从检查点续做，确定性主键加 `bulkPut` 保证绝不产生重复条目。
- **关联链检索**：地名文档反规范化图幅号、古名、今名、异写、沿革名与扫描件名；图幅文档汇集图幅号、题名与扫描件名。命中任一关键词即可沿 图幅 → 扫描件 / 地名 → 沿革 回到完整关联链。

索引器核心行为由 `frontend/test/search-index.test.ts` 覆盖（`npm run test:search`，基于 fake-indexeddb），包括首次建立、检查点续做、大批量取消后续做、增量重算、删除回收、损坏重建与关联链检索。

## 核心功能与路由表

| 路由 | 核心功能 |
| --- | --- |
| `/sheets` | 按年代、比例尺和状态筛选图幅，内联新建图幅，查看扫描件数、地名数与邻接缺编提示 |
| `/sheets/:id` | 查看编制摘要、扫描件条目、主用件切换、图内地名检索及 JSON 导出 |
| `/places` | 古今地名双栏对照，按类型和确定度筛选，对古名、今名、异写及图上方位反向查询并高亮 |
| `/search` | 本地关联检索：沿图幅号、古名、今名、异写、沿革与扫描件名命中并回到关联链，分页呈现 |
| `/places/:id/history` | 按年代排列沿革时间线，新增初置、改名、迁治或废置记录 |
| `/sheets/:id/neighbors` | 按四至排列邻接图幅，显示主用扫描件、缺编提示与拼合预览 |
| `/`、未匹配路径 | 自动跳转到 `/sheets` |
